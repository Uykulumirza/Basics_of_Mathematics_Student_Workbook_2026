# Exercise 8: Intersection Point of a Line and a Plane — Solution

## 1. Problem Statement

Find the intersection point of
$$(x,y,z)=(1,0,2)+t(1,2,-1)$$
with the plane $x+y+z=4$. Check the result by substituting it into both descriptions.

---

## 2. Theoretical Background and Concepts

To find the intersection of a line $L$ given in parametric form
$$(x, y, z) = P_0 + t v = (x_0 + t v_x, \, y_0 + t v_y, \, z_0 + t v_z), \quad t \in \mathbb{R},$$
and a plane $\Pi$ given in general form
$$Ax + By + Cz = d \quad (\text{i.e., } n \cdot X = d \text{ with } n = (A, B, C)),$$
we seek the parameter value(s) $t \in \mathbb{R}$ for which the moving point $X(t) = P_0 + t v$ satisfies the plane equation:
$$n \cdot (P_0 + t v) = d \iff (n \cdot v)\,t = d - n \cdot P_0.$$
When $n \cdot v \neq 0$, the line is not parallel to the plane and crosses it at a unique parameter value
$$t^* = \frac{d - n \cdot P_0}{n \cdot v}.$$
Substituting $t = t^*$ back into the parametric equation of $L$ produces the unique intersection point $Q = P_0 + t^* v$.

---

## 3. Detailed Step-by-Step Solution

### Step 1: Write the Coordinate Equations of the Line
From the parametric description $(x, y, z) = (1, 0, 2) + t(1, 2, -1)$, any point on the line $L$ has coordinates:
$$\begin{cases}
x(t) = 1 + t, \\
y(t) = 2t, \\
z(t) = 2 - t,
\end{cases} \quad t \in \mathbb{R}.$$
Here the base point is $P_0 = (1, 0, 2)$ and the direction vector is $v = (1, 2, -1)$, while the plane $x + y + z = 4$ has normal vector $n = (1, 1, 1)$. Notice that $n \cdot v = 1 + 2 - 1 = 2 \neq 0$, guaranteeing a unique intersection point.

### Step 2: Substitute the Line Coordinates into the Plane Equation
Substituting $x = 1 + t$, $y = 2t$, and $z = 2 - t$ into $x + y + z = 4$:
$$(1 + t) + (2t) + (2 - t) = 4.$$
Collecting the constant terms and the $t$-terms:
$$(1 + 2) + (1 + 2 - 1)t = 4$$
$$3 + 2t = 4.$$
Solving for $t$:
$$2t = 4 - 3 = 1 \implies t = \frac{1}{2}.$$

### Step 3: Compute the Coordinates of the Intersection Point
Substituting $t = \frac{1}{2}$ back into the parametric equation of the line:
$$\begin{aligned}
x\left(\tfrac{1}{2}\right) &= 1 + \frac{1}{2} = \frac{3}{2}, \\[4pt]
y\left(\tfrac{1}{2}\right) &= 2\left(\frac{1}{2}\right) = 1, \\[4pt]
z\left(\tfrac{1}{2}\right) &= 2 - \frac{1}{2} = \frac{3}{2}.
\end{aligned}$$
Therefore, the unique intersection point of the line and the plane is:
$$Q = \left(\frac{3}{2}, \, 1, \, \frac{3}{2}\right).$$

---

## 4. Verification and Consistency Checks

### 1. Checking that $Q$ Lies on the Line $L$
We check whether $Q = \left(\frac{3}{2}, 1, \frac{3}{2}\right)$ is generated by a single parameter $t$ in $(1, 0, 2) + t(1, 2, -1)$:
$$\begin{cases}
1 + t = \frac{3}{2} \implies t = \frac{1}{2}, \\[3pt]
0 + 2t = 1 \implies t = \frac{1}{2}, \\[3pt]
2 - t = \frac{3}{2} \implies t = \frac{1}{2}.
\end{cases} \quad \checkmark$$
All three coordinates match at $t = \frac{1}{2}$, so $Q \in L$.

### 2. Checking that $Q$ Lies on the Plane $\Pi$
We substitute the coordinates of $Q = \left(\frac{3}{2}, 1, \frac{3}{2}\right)$ into the plane equation $x + y + z = 4$:
$$\frac{3}{2} + 1 + \frac{3}{2} = \frac{3 + 2 + 3}{2} = \frac{8}{2} = 4. \quad \checkmark$$
Since $Q$ satisfies both the line equation and the plane equation, $Q = \left(\frac{3}{2}, 1, \frac{3}{2}\right)$ is verified as the exact intersection point.
